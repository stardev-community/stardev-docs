Cara pakai

Sama untuk lisensi Roblox script, mod APK, APK mandiri, web, maupun bot — semua lewat endpoint yang sama.

1. Deploy server

  1. Import repo ke project Vercel baru (root /).
  2. Buat Upstash Redis, isi UPSTASH_REDIS_REST_URL + TOKEN.
  3. Generate Ed25519: openssl genpkey -algorithm ed25519 -out ed25519.pem → ED25519_PRIVATE_KEY.
  4. Set ADMIN_SECRET, SITE_URL, dan PROTOCOL_MODE.
  5. (Opsional) token bot Telegram/Discord, lalu set-webhook.js.

2. Buat key

  1. Buka https://domain/admin, login dengan ADMIN_SECRET.
  2. Tekan Add Key: nama, masa aktif, maksimal HWID.
  3. Atau lewat AdminApp Android, bot Discord admin, atau POST /api/admin.

3a. Roblox script

Pakai dua ModuleScript dari client-templates/roblox:

local VerifyClient = require(path.to.VerifyClient)

local result = VerifyClient.verify(userKey, VerifyClient.getHwid())
if result and result.valid then
  print("Key sah, lanjut jalan")
else
  warn(result and result.message or "Gagal konek server")
end

Isi CONFIG (SITE_URL, MODE, AES/HMAC key). Jalankan CryptoClient.selfTest() sekali di Studio — semua harus PASS.

3b. APK / web / bot

Panggil endpoint verifikasi saat aplikasi start:

POST https://domain/api/verify
Content-Type: application/json

{"key":"SDV4-XXXX-XXXX","hwid":"android-id"}

→ {"valid":true,"expireAt":0,"plan":"lifetime"}

Mod APK & APK mandiri: ambil HWID dari Settings.Secure.ANDROID_ID atau gabungan model + ID. Simpan hasil verifikasi dengan masa cache singkat.

Mode protokol harus sama di server & klien

  • raw — JSON polos, paling cepat, andalkan HTTPS.
  • aes — payload AES-256-CBC, wajib kirim timestamp (anti-replay 300 detik).
  • aes_sign — AES + HMAC + tanda tangan Ed25519 pada respons; paling aman.

Kalau mode klien beda dengan PROTOCOL_MODE server, verifikasi akan gagal walau key benar.

Pertanyaan umum

Jawaban singkat sebelum membeli.

Ini versi V4 atau G3XStarDev?

V4 — KeySystemV4 (my-stardev-all-licence), versi terbaru yang menggabungkan lulux-licence, my-stardev-all-licence, dan AdminApp.

Bisa dipakai untuk lisensi apa saja?

Roblox script (.lua), mod APK, APK mandiri, aplikasi web, bot Discord/Telegram, atau tool internal. Selama klien bisa memanggil HTTP /api/verify, sistemnya jalan.

Apa bedanya paket 1 bulan dan Lifetime?

Source code sama-sama menjadi milik pembeli. Bedanya masa pembaruan dan dukungan: 1 bulan atau selamanya.

Apakah hosting dan bot token termasuk?

Tidak. Akun Vercel, Upstash Redis, token Telegram/Discord, dan domain diurus pembeli. Panduan deploy disertakan.

Bagaimana kalau key dibagikan?

Ada batas HWID per key, blokir otomatis setelah percobaan gagal berulang, blokir manual oleh admin, dan rate limit 5x/jam per HWID.

Boleh dijual ulang?

Tidak. Source untuk 1 brand/stack, boleh dimodifikasi untuk kebutuhan sendiri, tetapi tidak untuk dijual atau dibagikan ulang sebagai source.
