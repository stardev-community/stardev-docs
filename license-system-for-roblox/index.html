License system for Roblox scripts

A Roblox script cannot keep a secret. So the check cannot live in the script — it has to live on a server you control, and the script only gets a yes or no.

Where the check belongs

Roblox allows HttpService requests from server scripts only, to hosts you permit. That is the right place for verification: a server script asks your API, then hands the result to the rest of the system. A LocalScript cannot be trusted with a key or a secret.

local res = HttpService:RequestAsync({
    Url = "https://your-app.vercel.app/api/verify",
    Method = "POST",
    Headers = { ["Content-Type"] = "application/json" },
    Body = HttpService:JSONEncode({ key = key, hwid = hwid, app = "my-script" })
})
local ok = res.Success and HttpService:JSONDecode(res.Body).valid

What "HWID" means in Roblox

There is no hardware id. Use a stable per-player value tied to the place and a server-side record — for example the player's UserId plus a value stored in your own database. Treat it as a slot counter, not a fingerprint: the goal is limiting sharing, not identifying a device.
