Works where your product lives

Roblox scripts

Two ModuleScripts, one verify() call on connect, configurable protocol mode. Self-test included to validate the Lua crypto port against the server.

Mod APKs and standalone APKs

Call /api/verify on launch with a HWID built from ANDROID_ID plus device model. Cache the result briefly; fail closed or open per your policy.

Web apps, bots, desktop tools

Any HTTP client works. Plain JSON in raw mode, or AES/HMAC if you want application-layer protection.

Operational details people ask about

What happens if a key leaks?

HWID limits per key, temporary auto-blocks after repeated failures, permanent manual blocks, and a rate limit of 5 checks per hour per HWID.

Can I rebrand it?

Yes. One brand per purchase; storefront text, colors, and bot names are yours to change. The source is not for resale.

What do I need to run it?

A Vercel project, an Upstash Redis database, and an Ed25519 key pair. Telegram and Discord are optional.
