Membeli source code berarti kamu mendapat proyek yang harus kamu deploy sendiri. Karena itu isi paket harus jelas sebelum bayar, bukan setelah.

Isi paket

  • /api/verify — validasi key + HWID, masa aktif, batas perangkat, rate limit.
  • /api/admin, /api/hwid, /api/security — kelola key, blokir perangkat, baca log.
  • Panel admin web + app admin Android.
  • Bot Telegram pembeli dan bot Discord admin.
  • Storefront yang bisa diganti nama dan warna.
  • Client Luau: mode raw, AES, atau AES + HMAC, dengan self-test.
