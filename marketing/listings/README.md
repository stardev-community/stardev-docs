# Listing paket (opsi 1)

Tiga marketplace, satu produk. Pilih satu yang paling cepat kamu buat akunnya,
lalu StarAsitance isi listing-nya. Jangan pasang harga berbeda tanpa alasan —
kalau beda, jelaskan sebagai promo per kanal.

| Platform | Butuh | Pembayaran | Cocok untuk |
|---|---|---|---|
| SellMyCode | akun + verifikasi | platform (payout) | audiens yang memang cari source code |
| Gumroad | akun + payout bank | kartu/PayPal | internasional, checkout cepat |
| Fiverr | akun seller + verifikasi | platform | buyer yang mau sekalian jasa setup |

Status verifikasi & biaya platform **berubah-ubah** — cek sendiri sebelum listing.
Harga acuan: $6.50 / $12.50 (≈ Rp 100.000 / Rp 200.000).
