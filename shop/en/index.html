How it works

Same API for Roblox scripts, APKs, web apps, and bots.

1. Deploy

  1. Import the repo into a new Vercel project (root /).
  2. Create Upstash Redis, set URL + token.
  3. Generate Ed25519 key → ED25519_PRIVATE_KEY.
  4. Set ADMIN_SECRET, SITE_URL, PROTOCOL_MODE.
  5. Optional: Telegram/Discord tokens and webhooks.

2. Create keys

  1. Open /admin, log in with ADMIN_SECRET.
  2. Add key: name, expiry, max HWIDs.
  3. Or use the Android app, Discord bot, or POST /api/admin.

3a. Roblox

Drop in the two ModuleScripts from client-templates/roblox:

local result = VerifyClient.verify(userKey, VerifyClient.getHwid())
if result and result.valid then
  print("licensed")
else
  warn(result and result.message)
end

Fill CONFIG, then run CryptoClient.selfTest() once in Studio.

3b. APK / web / bot

POST https://your-domain/api/verify
Content-Type: application/json

{"key":"SDV4-XXXX-XXXX","hwid":"device-id"}

→ {"valid":true,"expireAt":0}

For Android use Settings.Secure.ANDROID_ID plus device model as HWID.

Keep the protocol mode identical

  • raw — plain JSON over HTTPS, fastest.
  • aes — AES-256 payload, requires timestamp (300s anti-replay).
  • aes_sign — AES + HMAC + Ed25519 signed responses.

Mismatched modes fail verification even with a valid key.
