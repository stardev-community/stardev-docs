StarDev Community.

Satu sumber kebenaran untuk semua UI dan video: warna, tipografi, jarak, radius, bayangan, dan komponen. Setiap proyek menunjuk ke sini — bukan menyalin gaya sendiri-sendiri.

Cara pakai

1DesainDesainmu masuk sebagai referensi: screenshot, Figma, atau SVG. Simpan di design/refs/.
2TokenNilai visual (warna, font, jarak) ditulis di tokens.json.
3Buildnode design/build.mjs menyuntik token ke halaman. Semua proyek ikut berubah.

Warna Color

Dipakai konsisten: latar gelap, satu brand amber, aksen per bidang.

Tipografi Type

Skala ukuran, bobot, dan tracking. Judul memakai tracking negatif, label memakai uppercase lebar.

Jarak, radius, bayangan Space

Skala 4px. Radius makin besar untuk elemen makin besar.

Komponen UI

Contoh nyata, bukan gambar. Semua memakai token di atas.
