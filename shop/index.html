StarDev All

Satu lisensi untuk seluruh ekosistem StarDev: StarDevXSchool Offline, AdminApp, StarDevNett, dan Key Lulu. Bayar QRIS, aktivasi langsung lewat WhatsApp.

Isi paket

Semua aplikasi dalam satu lisensi, pembaruan versi gratis.

  • StarDevXSchool Offline — presentasi offline: editor slide, OCR, export HTML, grafik otomatis.
  • AdminApp — kelola lisensi dan perangkat dari HP.
  • StarDevNett — berbagi berkas antar perangkat lewat socket.
  • Key Lulu — akses jajaran produk Lulu.
  • Dukungan WhatsApp — bantuan pemasangan dan aktivasi.

Alur pesanan

  1. Pilih perangkat & masa aktif, lalu tekan Pesan via WhatsApp.
  2. Admin mengonfirmasi ketersediaan dan nominal akhir.
  3. Bayar lewat QRIS, kirim bukti + kode pesanan.
  4. Lisensi dan panduan aktivasi dikirim di chat yang sama.

Pesanan diproses pada jam kerja. Simpan kode pesanan sampai lisensi aktif.

Pertanyaan umum

Jawaban singkat sebelum membeli.

Apakah lisensi bisa dipakai di beberapa HP?

Jumlah perangkat mengikuti paket yang dipilih (1–3). Lisensi terikat pada perangkat yang didaftarkan.

Apakah ada pembaruan?

Ya. Pembaruan versi dalam masa aktif dikirim lewat WhatsApp tanpa biaya tambahan.

Bagaimana kalau lisensi hilang?

Simpan kode pesanan dan key. Bila key hilang, hubungi admin dengan kode pesanan untuk pemulihan.

Metode pembayaran selain QRIS?

Saat ini QRIS. Untuk kebutuhan lain, tanyakan ke admin lewat WhatsApp.
