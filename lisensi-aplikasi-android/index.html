Lisensi aplikasi Android untuk developer indie

Kalau aplikasimu dijual di luar Play Store — mod, tools, atau APK langsung — kamu tidak punya pembayaran bawaan. Di situ lisensi buatan sendiri masuk.

Empat jalur

JalurCocok untukCatatan
Play BillingAplikasi di Play StorePaling patuh, tapi potongan platform
Key manual (tanpa server)Beberapa pembeliCepat, tapi tidak bisa dicabut
Key + HWID dengan backend sendiriPenjualan berulangKontrol penuh, perlu deploy
Layanan lisensi pihak ketigaIngin cepatBiaya berulang, data di vendor

Yang wajib ada di klien

  • Grace period offline yang terbatas, bukan akses penuh.
  • Penyimpanan token, bukan key mentah.
  • Pesan error yang jelas: kedaluwarsa, salah perangkat, atau server down.
  • Versi aplikasi dikirim saat verifikasi agar kamu bisa memaksa update.

Distribusi APK

Setiap APK bisa dibongkar; yang tidak bisa dibongkar adalah validasi di server. Karena itu jangan menaruh rahasia di APK, dan jangan mengandalkan obfuscation sebagai satu-satunya perlindungan.

Kapan pakai source siap pakai

Kalau kamu butuh panel admin, pembatasan perangkat, bot pembeli, dan pencatatan percobaan gagal tanpa menulis backend dari nol, source code lebih cepat daripada membangun sendiri.
