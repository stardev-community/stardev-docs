Sistem lisensi milik sendiri, bukan sewa bulanan

KeySystemV4 adalah source code lengkap sistem lisensi: verifikasi key + HWID, panel admin, app admin Android, bot Telegram, dan bot Discord. Deploy di akun Vercel dan Upstash kamu sendiri — data key tetap di tanganmu.

Kenapa beli source, bukan langganan

  • Tidak ada tagihan bulanan ke pihak ketiga; cukup kuota gratis Vercel/Upstash untuk skala kecil.
  • Key, HWID, dan log tersimpan di database kamu.
  • Bisa diubah: limit device, masa aktif, pesan error, tampilan panel.
  • Tidak ada risiko harga naik atau layanan tutup.

Konsekuensinya: kamu yang deploy, backup, dan update. Ada panduan langkah demi langkah di dalam paket.

Pertanyaan yang sering muncul

Ini jual lisensi pakai atau source code?

Source code. Setelah bayar kamu menerima arsip proyek dan deploy sendiri. Tidak ada akses ke server kami, karena servernya milikmu.

Bisa untuk jualan key ke orang lain?

Bisa. Sistem ini memang dibuat untuk itu: kamu jadi pemilik stok key dan menentukan harga sendiri.

Kalau source-nya bocor?

Kode yang bocor tidak otomatis membuka akses, karena validasi tetap di server dan database kamu. Yang perlu dijaga adalah secret admin dan pasangan kunci Ed25519.
