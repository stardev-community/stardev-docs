Tujuan: buyer pertama dalam 7 hari. Semua bahan siap tempel; kamu tinggal
konfirmasi dan kirim.

**Batas jujur:** StarAsitance tidak bisa mendaftarkan akun, menerima uang, atau
mengirim DM massal atas namamu. Yang bisa dilakukan: menyiapkan listing, memilih
kanal, menulis pesan, dan (kalau kamu mau) menjalankan pengiriman satu per satu
lewat HP dengan kamu menyetujui tiap kiriman.

## Urutan kerja

1. **Hari 1 — pasang etalase.** Daftar 1 akun marketplace yang tidak perlu
   verifikasi berat: Gumroad atau Payhip. Upload `shop/og.png` sebagai cover,
   isi deskripsi dari `listing-en.md`, harga $6.50 / $12.50, file = arsip source
   atau link repo privat (kirim manual setelah bayar).
2. **Hari 1 — pasang bukti.** Screenshot panel admin (`shop/docs/ui-admin.png`),
   daftar isi source, dan struktur folder. Buyer luar negeri tidak kenal kamu;
   bukti visual menutup celah itu.
3. **Hari 2–3 — masuk kanal.** Pakai `targets.md`. Ikuti aturan tiap server;
   jangan spam. Posting di channel promosi, bukan DM acak.
4. **Hari 3–5 — outreach langsung.** Pakai `outreach.md` ke pemilik script hub,
   modder APK, dan reseller. Maksimal 10 pesan/hari, personal, bukan blast.
5. **Hari 5–7 — tindak lanjut.** Follow-up sekali setelah 48 jam. Tawarkan
   diskon peluncuran $5 / Rp 80.000 untuk 3 buyer pertama.

## Aturan main

- Jangan klaim "terjual 1000+", "official", atau "aman 100%". Bukti yang ada:
  source code nyata, panel admin, dan dokumentasi.
- Jangan janjikan bypass anti-cheat atau akses game tertentu.
- Hormati aturan tiap komunitas. Banyak server melarang jualan di general chat;
  gunakan channel `#marketplace` / `#self-promo` atau minta izin owner.
- Satu buyer = satu stack. Jangan jual ulang source ke beberapa buyer sekaligus.
