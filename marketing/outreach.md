# Outreach

Kirim maksimal 10 pesan/hari, satu per orang, bukan blast. Setiap pesan harus
menyebut produk mereka — bukan template mentah.

## 1. Pemilik script hub (EN)

```
Hey <name> — I saw <hub> uses a key system for your users.

I build/sell the source of one: self-hosted on Vercel + Redis, web admin panel,
Android admin app, Telegram buyer bot, Discord admin bot, HWID limits, AES/HMAC.

It's $6.50 for a 1-month-updates license or $12.50 lifetime, one brand per
purchase. Demo screenshot + docs: <link>

If you're already paying for a hosted key service, this replaces the recurring
cost. Want me to send the setup checklist?
```

## 6. Jawaban keberatan

**"Mahal / kenapa bukan gratisan?"**
> Yang gratis biasanya hosted dan bisa mati kapan saja. Ini source: kamu deploy
> sendiri, tidak ada biaya bulanan ke saya. Sekali bayar.

**"Gimana kalau source-nya di-crack?"**
> Source-nya kamu yang pegang; tidak ada lisensi yang bisa dicabut. Untuk
> produk kamu sendiri, yang penting HWID + signature Ed25519 aktif.

**"Bisa setup-in sekalian?"**
> Bisa, add-on Rp 150.000 / $10: deploy Vercel, Redis, Ed25519, bot token, dan
> satu integrasi klien.

**"Boleh dijual ulang?"**
> Tidak. 1 brand per pembelian. Kalau mau untuk beberapa klien, ambil bundle
> 2–3 brand dengan harga khusus.

**"Ada demo?"**
> Kirim link toko + screenshot panel admin. Jangan kirim source sebelum bayar.

**"Bayar pakai apa?"**
> Indonesia: QRIS. Luar negeri: Binance Pay / USDT. Konfirmasi nominal di chat.

## 7. Yang jangan dilakukan

- Jangan kirim file source sebagai "sample".
- Jangan janji "anti-banned", "bypass", atau akses game tertentu.
- Jangan DM member biasa di server; hanya owner/admin atau channel promo.
- Jangan klaim angka penjualan yang tidak ada.
